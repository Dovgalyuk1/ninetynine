# NINETY NINE — $99

Одностраничный мем-сайт: название, описание, кнопки и мини-игра. Без гейта и прелоадера — открывается сразу.

## Идея
Установка встала на 99%. Она двигается только когда он упирается в неё плечом. Каждый раз, когда последний процент дожат, внутри него находится ещё один последний процент.

## Фишка — THE LAST PERCENT
- Удерживай **HOLD TO SHOVE** (или пробел) — полоса ползёт, GRIP тратится.
- GRIP до нуля → срыв: откат прогресса, тряска, звук. Толкать надо очередями.
- Отпустил больше чем на 0.75 с — полоса медленно откатывается сама.
- Процент дожат → камера проваливается внутрь последнего процента (zoom), счётчик получает ещё одну девятку: 99% → 99.9% → … → 99.9999999%.
- 8 уровней, на каждом находится предмет — он всплывает в статус-строке, а квадратик в ряду прогресса закрашивается.
- Финал: INSTALL COMPLETE + дождь монет.

## Оформление
- Палитра: кислотный лайм `#93f621`, инсталлер-синий `#1f86fa`, чернила `#0d1206`, золото `#ffd227`.
- Шрифты: Silkscreen (пиксельный display) + IBM Plex Mono.
- Пиксель-арт персонажа, `image-rendering: pixelated` везде.
- Музыка: «installer muzak» — арпеджио в 6/8, которое поднимается и вежливо возвращается в исходную ноту. Web Audio, без файлов.
- Звуки: толчок, срыв, открытие уровня, монеты.

## Структура
`index.html` — весь сайт (стили и скрипты инлайн), `assets/` — вырезанный персонаж и кропы.

## Настройка перед листингом
В начале `<script>` в `index.html`:

```js
window.CONTRACT = "";   // адрес контракта
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // ссылка на покупку
```

Пока `BUY_URL` пустой — кнопка BUY серая и неактивна. `CONTRACT` подставляется в чип CA (клик = копирование) и в ссылку на DexScreener.
